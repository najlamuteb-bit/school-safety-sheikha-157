# بوابة الأمن والسلامة المدرسية

إعداد: شيخه العتيبي

موقع عربي باتجاه من اليمين إلى اليسار، بألوان رسمية كحلية وخضراء داكنة.

## التشغيل
افتح ملف index.html في المتصفح. لا يحتاج الموقع إلى تثبيت مكتبات أو خطوة بناء.

## تعديل الأسماء
استخدم زر «تعديل الأسماء» في الصفحة الرئيسية. أسماء أعضاء الفريق والطلاب تُعدّل داخل نماذجها.

## حفظ البيانات
تحفظ البيانات في المتصفح على الجهاز المستخدم. لنقل البيانات إلى جهاز آخر استخدم تصدير واستيراد النسخة الاحتياطية. لا يتضمن هذا المستودع بيانات طلاب أو موظفات مُدخلة في النماذج.

## محتويات الموقع
- تسلسل التنفيذ
- مصفوفة الفريق
- خطة الإخلاء
- الخطة الفردية
- إدارة التمرين
- بطاقة الالتزام
- سجل الأمن والسلامة
